# Bank Account Management System

## Project Overview

A Java console application that simulates basic bank account operations.

## Features
- Create an account with an opening balance
- Deposit money
- Withdraw money with balance validation
- Display the current balance
- Handle invalid menu choices and numeric input

## OOP Concepts
- **Encapsulation:** Account details and balance are private.
- **Classes and Objects:** A `BankAccount` object stores account information.
- **Methods:** Deposit, withdrawal, and balance display are separate methods.
- **Validation:** Invalid amounts and insufficient funds are handled.

## Project Structure
- `src/BankAccountManagementSystem.java`
- `README.md`

## How to Run
Compile from the repository root:

`javac -encoding UTF-8 -d "Bank-Account-Management-System\out" "Bank-Account-Management-System\src\BankAccountManagementSystem.java"`

Run:

`java -cp "Bank-Account-Management-System\out" BankAccountManagementSystem`

## Requirements
- JDK 17 or later

## Learning Outcome
Practice Java classes, objects, encapsulation, methods, loops, and input validation.
