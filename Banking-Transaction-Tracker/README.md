# Banking Transaction Tracker

A beginner-friendly Java console application for tracking deposits, withdrawals, and account balance.

## Features
- Deposit money
- Withdraw money
- Prevent invalid or non-positive transactions
- Prevent withdrawals beyond the available balance
- Check current balance
- Menu-based interaction

## Requirements
- Java JDK 17 or later

## Run the project

Open a terminal in this folder and run:

```bash
javac src/BankingTransactionTracker.java
java -cp src BankingTransactionTracker
```

## Concepts Used
- Java Scanner
- do-while loop
- switch statement
- if-else conditions
- Input validation
- Basic arithmetic
