# 🚕 Cab Fare Calculator

A simple Java program that calculates cab fare based on cab type, distance, and night ride charges.

## ✨ Features

- Enter passenger name
- Select cab type
- Calculate fare based on distance
- Add night ride charge
- Validate distance and cab type

## 💰 Cab Rates

| Cab Type | Rate per KM |
|----------|-------------|
| Bike | Rs. 10 |
| Auto | Rs. 12 |
| Car | Rs. 15 |

## 🛠️ Technologies

- Java
- Scanner
- If-else statements

## ▶️ Run

```text
javac CabFareCalculator.java
java CabFareCalculator
