# 🚗 Driving Licence Eligibility Checker

A simple beginner-friendly Java console application that checks whether a person is eligible to apply for a driving licence based on age.

## 📌 Eligibility Rules

- Age 18 or above: Eligible
- Age below 18: Not eligible
- Negative age: Invalid input

## ✨ Features

- Accepts the user's name and age
- Checks driving licence eligibility
- Displays the remaining years for eligibility
- Handles negative age input

## 🧠 Java Concepts Used

- Variables
- Scanner class
- User input
- if-else statements
- Arithmetic operations
