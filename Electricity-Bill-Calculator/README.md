# ⚡ Electricity Bill Calculator

A simple Java console application that calculates an electricity bill based on the number of units consumed.

## ✨ Features

- Accepts the customer name
- Accepts electricity units consumed
- Calculates the electricity bill
- Validates negative unit input
- Displays a clear bill receipt
- Uses beginner-friendly Java code

## 💰 Electricity Charges

| Units Consumed | Rate |
|---|---:|
| Up to 100 units | Rs. 1.50 per unit |
| 101 to 200 units | Rs. 2.50 per unit |
| Above 200 units | Rs. 4.00 per unit |

## 🧮 Formula

Electricity Bill = Units Consumed x Applicable Rate

## 🖥️ Sample Output

    === Electricity Bill Calculator ===
