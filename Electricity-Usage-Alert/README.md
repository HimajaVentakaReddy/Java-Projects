# Electricity Usage Alert

A beginner-friendly Java application that estimates electricity cost and alerts users about high consumption.

## Features
- Accepts electricity units and a user-defined alert threshold.
- Estimates cost using simple unit-based rates.
- Alerts when consumption exceeds the threshold.
- Validates input values.

## Technologies
Java, Scanner, if-else, arithmetic operations.

## Run
```powershell id="4g0e2d"
javac -d out src/ElectricityUsageAlert.java
java -cp out ElectricityUsageAlert
```

## Note
The rates are illustrative examples for learning, not official electricity tariff rates.
