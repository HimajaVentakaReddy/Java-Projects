# Employee Attendance Tracker

## Project Overview

A simple Java console application that calculates an employee's attendance for a 30-day period.

## Features

- Accepts an employee name
- Records days present
- Calculates days absent and attendance percentage
- Validates attendance input
- Displays an attendance status

## Java Concepts Used

- Variables and data types
- Methods
- Loops and conditional statements
- Exception handling
- Scanner for user input

## Project Structure

- `src/EmployeeAttendanceTracker.java`
- `README.md`

## How to Run

Compile from the repository root:

`javac -encoding UTF-8 -d "Employee-Attendance-Tracker\out" "Employee-Attendance-Tracker\src\EmployeeAttendanceTracker.java"`

Run:

`java -cp "Employee-Attendance-Tracker\out" EmployeeAttendanceTracker`

## Requirements

- JDK 17 or later

## Learning Outcome

Practice input validation, calculations, loops, methods, and conditional statements in Java.
