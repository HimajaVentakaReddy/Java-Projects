# Exam Eligibility Checker

A simple Java console application that checks whether a student is eligible to attend an examination.

## Eligibility Requirements

A student is eligible when:

- Attendance is at least 75%
- Internal marks are at least 40
- Examination fees are paid

## Features

- Accepts the student name and USN
- Checks attendance and internal marks
- Checks examination fee status
- Displays the eligibility result
- Shows reasons for ineligibility

## Java Concepts Used

- Variables and data types
- Scanner class
- If-else statements
- Logical operators
- String comparison
- Console input and output

## How to Compile

javac -d Exam-Eligibility-Checker\out Exam-Eligibility-Checker\src\ExamEligibilityChecker.java

## How to Run

java -cp Exam-Eligibility-Checker\out ExamEligibilityChecker
