# 🌡️ Fever Checker

A simple beginner-friendly Java program that checks body temperature and displays the temperature status.

## ✨ Features

- 👤 Enter person's name
- 🌡️ Enter temperature in Celsius
- ✅ Check temperature status
- ⚠️ Validate invalid temperature
- 📋 Display a simple temperature report

## 📊 Temperature Categories

| Temperature | Status |
|---|---|
| Below 37°C | Normal |
| 37°C to below 38°C | Mild Temperature |
| 38°C or above | Fever |

## 🛠️ Technologies Used

- Java
- Scanner
- If-else statements

## ▶️ How to Run

```text
javac FeverChecker.java
java FeverChecker
