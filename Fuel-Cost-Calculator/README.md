# Fuel Cost Calculator

A beginner-friendly Java console application to estimate fuel requirements and travel cost.

## Features
- Calculates fuel required from distance and mileage.
- Estimates the total fuel cost.
- Validates positive input values.

## Technologies
Java, Scanner, if-else, arithmetic operations.

## Run
```powershell
javac -d out src/FuelCostCalculator.java
java -cp out FuelCostCalculator
```
