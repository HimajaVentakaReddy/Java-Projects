# Hotel Room Cost Calculator

A Java console application to estimate hotel accommodation charges.

## Features
- Three room types with different nightly rates.
- Calculates the total cost based on nights booked.
- Validates room selection and stay duration.

## Technologies
Java, Scanner, if-else, arithmetic operations.

## Run
```powershell
javac -d out src/HotelRoomCostCalculator.java
java -cp out HotelRoomCostCalculator
```
