# 💼 Job Eligibility Checker

## 📌 Problem Statement

A simple Java program that checks whether a person is eligible for a job based on age and required qualification.

## 🎯 Features

- Accepts candidate name
- Checks candidate age
- Validates qualification
- Supports different job types
- Displays eligibility status
- Handles invalid age

## 🛠️ Technologies Used

- Java
- Scanner
- Conditional Statements
- User Input

## ▶️ Example

Enter your name: Hima
Enter your age: 22

Select Job Type:
1. Software Job
2. Government Job
3. General Job

Enter choice: 1
Do you have the required qualification? (yes/no): yes

Job Eligibility Result
----------------------
Name: Hima
Status: Eligible for Job

## 📚 Concepts Practiced

- Variables
- Scanner
- if-else
- Boolean conditions
- String comparison
- User input validation
