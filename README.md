## 📂 Projects

### 1. BillWise — Smart Invoice Anomaly Detection Engine

A Java application that analyzes invoice data and identifies possible anomalies.

#### Key Features

- Detects duplicate invoices
- Identifies unusually high amounts
- Validates invoice values
- Detects tax mismatches
- Identifies future-dated invoices
- Checks for missing vendor information

📁 [View BillWise Project](BillWise-Smart-Invoice-Anomaly-Detection-Engine)

### 2. Driving Licence Eligibility Checker

A beginner-friendly Java console application that checks whether a person is eligible to apply for a driving licence based on age.

#### Key Features

- Accepts the user's name and age
- Checks eligibility using `if-else`
- Displays the remaining years for eligibility
- Handles negative age input
