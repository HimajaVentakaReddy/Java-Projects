# Shopping Discount Calculator

A simple Java console program that calculates shopping discounts and final prices.

## Features
- Accepts the original price and discount percentage.
- Calculates the amount saved.
- Displays the final price.
- Validates price and discount inputs.

## Technologies
Java, Scanner, if-else, arithmetic operations.

## Run
```powershell
javac -d out src/ShoppingDiscountCalculator.java
java -cp out ShoppingDiscountCalculator
```

## Example
Original price: Rs. 2000
Discount: 10%

Discount amount: Rs. 200.00
Final price: Rs. 1800.00
