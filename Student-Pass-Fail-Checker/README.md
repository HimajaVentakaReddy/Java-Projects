# Student Pass/Fail Checker

## Project Overview

A Java console application that calculates student marks, subject results, grades, and overall academic performance.

## Features

- Accepts student name and USN
- Validates marks between 0 and 100
- Calculates total marks and average percentage
- Identifies failed subjects
- Assigns grades and performance classifications
- Displays a formatted result report

## Java Concepts Used

- Arrays to store subject names and marks
- Loops to collect marks and display results
- Methods for validation, subject results, and grading
- Conditional statements for grade calculation
- Exception handling for invalid numeric input

## How to Run

Compile from the repository root:

`javac -encoding UTF-8 -d "Student-Pass-Fail-Checker\out" "Student-Pass-Fail-Checker\src\StudentPassFailChecker.java"`

Run:

`java -cp "Student-Pass-Fail-Checker\out" StudentPassFailChecker`
