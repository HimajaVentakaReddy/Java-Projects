# Travel Budget Checker

A simple Java console application that tracks travel expenses against a budget.

## Features
- Accepts a travel budget and four expense categories.
- Calculates total spending.
- Displays the remaining budget or excess spending.
- Validates user inputs.

## Technologies
Java, Scanner, if-else, arithmetic operations.

## Run
```powershell id="z3u0fk"
javac -d out src/TravelBudgetChecker.java
java -cp out TravelBudgetChecker
```

## Example
Budget: Rs. 10000
Total expenses: Rs. 7500
Remaining budget: Rs. 2500
